# Portrait asset

Add the approved portrait as `portrait.webp` in this directory. The source should be at least 1200 pixels on its shortest displayed axis; a 4:5 portrait crop is recommended so the composition remains useful from mobile through wide editorial layouts.

Do not substitute a generated likeness. Until an approved photograph exists, the interface should render its explicit CSS placeholder.

When the asset is added, replace placeholder alternative text with a concise description of the real photograph and its relevant context. Do not describe inferred identity, mood, ethnicity, or other details that cannot be verified from the approved source.

## Placeholder label

Until `portrait.webp` exists, the interface renders a typographic block that reads
`PORTRÄT FOLGT / PORTRAIT TO FOLLOW`. Keep that wording in both locales so the
absence of a photograph is stated rather than implied.
